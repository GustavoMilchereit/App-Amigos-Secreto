🎁 Amigo Secreto da Família

Sorteio sem servidor. Cada pessoa recebe no WhatsApp ou por SMS um link pessoal criptografado e assinado. Este painel não guarda quem tirou quem.

1. Evento

O endereço precisa estar publicado na internet (ex.: GitHub Pages ou Netlify), senão os links não abrem no celular dos participantes. Preencha data e valor antes de sortear: eles vão cifrados dentro de cada link.

2. Participantes

Uma pessoa por linha: Nome; Telefone; Grupo. O grupo é opcional: pessoas do mesmo grupo (casal, pais e filhos pequenos) não tiram umas às outras. Também dá para colar direto do Excel ou do Google Sheets.

3. Divulgar o selo no grupo da família

Todo link verdadeiro mostra exatamente estes emojis. Se algum primo fabricar um link falso, o selo vai aparecer diferente ou a página vai acusar adulteração.

4. Enviar os links

A mensagem leva só o link pessoal cifrado. Este painel não guarda quem tirou quem. Não abra os links dos outros.
